# lomtalanitunk.hu

Static website for a Hungarian small-business waste-removal and property-clearance service.

This project is intentionally lightweight: it is a traditional static website rather than a framework-based web application.

## Stack

- HTML
- CSS
- JavaScript
- Apache `.htaccess`

## Included

- Service and information pages
- Contact page
- Privacy and imprint pages
- SEO-oriented article pages
- `robots.txt`
- `sitemap.xml`
- Responsive site styling
